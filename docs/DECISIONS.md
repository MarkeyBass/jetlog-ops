# JetLog — Decisions in force

**The living decision log** — what was decided, and why. Don't relitigate a decision without a new entry here (`/decision`).

- **Append-only.** A new standing decision is a new row at the bottom; prefix its *why* with the date (`**YYYY-MM-DD.** …`). A row that changes an earlier one supersedes it — never rewrite history.
- **One-off deferrals** (things deliberately not built now) go to [BACKLOG.md](BACKLOG.md), not here.
- **Task numbers** in these rows refer to the plan current at the time: tasks 1–32 are the post-POC plan, [archive/2026-10-post-poc-plan.md](archive/2026-10-post-poc-plan.md); tasks 33 on are the UI-redesign plan, [PLAN.md](PLAN.md) (archived plans keep their own numbers; numbering continues across plans).
- The POC-era decision log in [archive/POC_PHASES.md](archive/POC_PHASES.md) is frozen and historical — do not add to it.
- This file lived in `docs/HANDOFF.md` §3 until 2026-10-14; older rows and commits still say "HANDOFF §3".

Auto-`sync()` DDL is unsafe near production. Switching = rewrite every query, migrations, seed, test harness for zero feature value. |

| **Component library = shadcn + Tailwind (not MUI)** | **2026-09-27.** Mark's call, settling the row above. shadcn/Tailwind is where the industry is now, is lighter and more flexible for a token-driven restyle (the coming client redesign), and is far friendlier to agent-driven UI work; MUI is heavier and older. Mark has shipped both — no strong contest. |
